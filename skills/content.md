# Skill: MPC Content

## Mission
Turn real questions and problems into understandable learning material.

## Case structure
Problem
→ Keywords + Units / Numbers
→ Deconstruct → Small Problems
→ Image (optional)

Current Cases UI stores only this structure. Do not assume Knowledge needed, Solve, Return or Lesson fields exist unless the product explicitly adds them later.

## Terms
Separate:
1. Official meaning
2. Source
3. MPC explanation
4. Community explanations / analogies

Do not replace a sourced definition with a community interpretation.

## Map
Map nodes should become useful because cases use them. Avoid building an encyclopedia for its own sake.

## Tools
A tool belongs in MPC when it has a clear role in exploration, simulation, visualization or solving.

## Writing style
- Prefer plain Vietnamese when possible.
- Explain the idea before terminology.
- Use examples and visuals where useful.
- Avoid exam-oriented framing.
- Do not pretend an unresolved question is solved.
